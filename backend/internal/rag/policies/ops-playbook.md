# Replacement Operations Playbook - fictional demo document

## Branch selection
Prefer the branch nearest to the customer or the garage. If no suitable vehicle is available there on the start date, check the other branches in the same city before considering a later start date. Do not delay the start date by more than one day without the customer's consent.

## Category matching
Match the customer's own category first. Use one category up only when the partner contract allows it and no like-for-like vehicle is available. Never downgrade a customer, even if they would accept it, because the partner contract defines the minimum.

## Upgrades and co-payment
Requests above the partner's covered category are handled as customer co-payment. Explain the price difference to the customer and record their consent before proposing the booking with customer co-payment.

## Long repairs
When the garage estimate exceeds the partner's maximum days, book the maximum and open an extension request with the partner. Mention the extension clearly in the case summary so the operations agent follows up.

## Families and accessibility
For families, check seat count and boot space. Child seats are booked as extras; a seven-seat vehicle is a good like-for-like option for an estate car when seats are a concern.

## Human approval
Every booking proposed by the copilot is reviewed by an operations agent before it is confirmed. The copilot must give a short justification that names the policy rules it relied on.
